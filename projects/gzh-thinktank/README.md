# X•超玩未来智能作品工作区

此目录位于工作流源代码之外，保存文章工作区、过程证据、预览、发布回执和归档。
工作流源代码位于 `gzh_未来智能`，作品统一写入本目录，不要写回源仓库。

## 作品命名

每篇新作品由工作流自动分配一个独立目录：

```text
THK-YYYYMMDD-NNN-主题slug/
```

- `THK`：X•超玩未来智能 `thinktank` 账号前缀；
- `YYYYMMDD`：工作区创建日期；
- `NNN`：当天由 `registry/workspace-index.json` 原子递增分配；
- `主题slug`：标题的人读短名，不作为唯一身份。

每篇作品只保留一套标准文件。制作中更新该作品目录内的文件；历史检查点进入该作品的 `snapshots/`，不创建第二套阶段副本。

## 生命周期

作品目录只能位于一个生命周期目录：

```text
active/      制作中
delivered/   已完成交付或已提交草稿
archive/     长期归档
quarantine/  异常或待人工判断
```

生命周期变化时移动整个作品目录，不复制文章内容。`registry/` 保存所有作品的登记、路由和锁；`inbox/` 保存经批准的 handoff 输入副本；`tmp/` 只保存可重建缓存。
