# 主题簇｜MCP工具调用之后，谁来管Agent的下一步？

> 本簇所有文章必须回到“MCP工具调用的生产治理”，不得扩展成泛Agent入门或模型评测。

## 核心母题

Agent可以调用工具之后，谁来约束它的下一步、记录它的理由，并在异常时停下或恢复？

## 相邻选题与内容缺口

1. MCP工具调用边界：从工具清单到执行结果——定义权限与审计的输入合同。
2. 时间序列授权：为什么要检查连续动作——补足单次allowlist看不到的组合风险。
3. 显式工具许可：让Agent的下一步可被批准——把调用前权限变成可检查门禁。

## 复用边界

可派生：工具权限、序列策略、审计字段和验收清单；不可替代：任何来源的版本范围、原文定位和具体适用边界。
