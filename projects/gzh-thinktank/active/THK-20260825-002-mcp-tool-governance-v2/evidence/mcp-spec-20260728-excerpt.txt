Make MCP stateless: remove the initialize/initialized handshake. Every request now carries its protocol version and client capabilities in _meta. Multi Round-Trip Requests (MRTR) use resultType: "input_required" and inputResponses on a retry. The changelog also documents OpenTelemetry trace context keys (traceparent, tracestate, baggage) and requires Mcp-Method and Mcp-Name headers for Streamable HTTP POST requests.
