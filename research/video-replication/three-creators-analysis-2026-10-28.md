# 三位新对标博主制作手法拆解 + GitHub 可复现项目

> 对象：柱子哥、花叔、秋芝2046（用户口述"秋芝1026"实为"秋芝2046"）
> 方法：抖音搜索接口召回目标视频逐字稿 + GitHub 仓库坐实。证据分级：✅口播逐字稿 / 🔶画面推断 / ❓待实片。

---

## Part 1 制作手法拆解

### A. 柱子哥（20万粉，AI+商业案例）

**他不是"视频特效型"博主，是"内容架构型"博主**——制作层面轻，但内容工程重。

| 维度 | 事实 | 证据 |
|---|---|---|
| 定位 | 用AI工作流讲全球商业科技案例；人群=想用AI搞懂商业的超级个体 | ✅拆解视频逐字稿 |
| 内容三段式 | 前端商业案例选题（拉流量）→ 中段AI工作流干货（留专业信任）→ 后端超级个体方法论收口（筛付费） | ✅ |
| 选题配比 | 每周3个商业案例 + 2个AI工具工作流 + 1个超级个体复盘 | ✅ |
| 时长 | 卡死 2:03 | ✅ |
| 节奏公式 | **3秒爆点数据 → 30秒案例来龙去脉 → 60秒硬干货（工作流截图+提示词要点）→ 30秒收口到一人公司场景** | ✅ |
| 生产分工 | AI写初稿+套模板出图，人只做判断和修改；每期带可下载SOP飞书文档（模板/踩坑/错题集） | ✅ |
| 变现 | 会员制前置（财富自由团），不挂微信不私信，评论区AI agent软引导 | ✅ |

**可复刻点**：他的"截图+提示词要点"硬干货段，正好是 Build 组允许的静态截图/指标图范畴；"30秒收口到一人公司"是我们"能力变现"栏目的母版。**不要复刻他的颜值/口播风格，要复刻他的内容配比和节奏公式。**

---

### B. 花叔（= `huashu-art-motion` 作者）

**他是"代码渲染动画"路线的代表**——画面不是视频模型生成的，是 Claude/Codex 写代码一帧帧画出来的。

| 维度 | 事实 | 证据 |
|---|---|---|
| 核心方法 | 给 Codex 输入：口播稿 + 画幅 + 时长 + **每句话对应什么画面动作**；它出动画方法+配套代码，按文字/曲线数据/时间点导出片段 | ✅逐字稿 |
| 工作流 | 先看短预览 → 确认动作与口播对齐 → 再配音加字幕 → 逐段人工检查 | ✅ |
| 风格库 | **35种艺术风格**（梵高/莫奈/古埃及壁画/像素游戏…）+ **9种解说动画讲法**（3Blue1Brown式/白板/动态文字…） | ✅仓库README |
| 代表案例 | 梯度下降曲线：先画曲线再亮重点，画面跟着讲解走 | ✅ |

**可复刻点**：这是 Build 组（未来智能，零录屏）的标准答案——纯代码矢量动画，天然满足"禁录屏"红线。**直接装他的开源 skill，不要自己写动画引擎。**

### C. 秋芝2046（150万粉，产品经理出身）

**她是"说明书式长教程"路线**——收藏率=点赞率，靠"值得回来查"取胜。

| 维度 | 事实 | 证据 |
|---|---|---|
| 双平台 | B站月更20分钟深度（立技术人设）；抖音砍成60秒短平快（吸量） | ✅ |
| 两类内容 | 首发实测新模型（吃时效，均7.7万赞）vs 教程（吃收藏，均13.8万赞/7.9万收藏） | ✅账号拆解逐字稿 |
| 标题公式 | **标题性报价**："40分钟学会Codex"，实际40:28，说到做到范围/成本/交付物 | ✅ |
| 结构 | 进度条切10段（安装/上手/文件操作/记忆/插件/skills/自动化…每段可跳转）；**先给结果再讲门槛**（5:25先上手，6:55才讲安装）；简介写成本（"耗时近1个月"） | ✅ |
| 视觉/动效 | 口播+MG动效：声波游戏、像素厨师闪现入场、橙色矩形框黑底、得意黑字体、左移/弹动/渐隐/刷屏循环 | ✅1:1口播拆解逐字稿 |
| 生产观 | AI做80%机械框架，人做20%灵魂（开头/案例/结论自己写）；内容同步沉淀飞书知识库 | ✅ |
| 粉丝画像 | 76%男，31-40岁，都市白领北上广深——"拿AI去上班的打工人" | ✅ |

**可复刻点**：她证明了**收藏率才是知识号的核心权重**（抖音算法已把"收藏+复播"纳入长期价值信号）。这直接指导我们：Build组要做"可回来查的说明书"，不是"看完就划走的爽片"。动效层（得意黑/像素风/黑底橙框）可参考 huashu-art-motion 和 lemo-opuscar 的现成风格。

## Part 3 对 ContentOps 的映射（写进对应模块）

1. **Build组（未来智能）动画层不要自研**：P0 先装 `xilo-opus-video` 当管线骨架，风格从 `huashu-art-motion` + `lemo-opuscar` 取。这比 M4b 自己写矢量图生成器快一个数量级。
2. **A组（1024 Explore）**：吸收柱子哥节奏公式（3s爆点/30s/60s/30s收口），但画面仍用干净录屏+脱敏。
3. **收藏率优先**：秋芝证明知识号靠"说明书+可回查"，不是靠短。我们的长教程选题要切分进度段、标题写报价、先结果后门槛。
4. **生产分工**：AI出初稿+代码渲染，人只做判断/选风格/逐段验收——和仓库"人盯20%决策"一致。
