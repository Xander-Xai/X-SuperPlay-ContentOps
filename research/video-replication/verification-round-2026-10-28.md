# 对标视频复核（第二轮）：逐字稿级验证

## 复核方式与局限（先说清楚）

- 抖音 MP4 直接下载被风控：API 403 + 本机 cookie 过期 + 浏览器 cookie DPAPI 解密失败，**未拿到视频文件本身**。
- 改用抖音搜索接口召回目标视频，拿到**完整 ASR 逐字稿** + 点赞/评论快照。
- 因此：叙事结构、工具链口播证据、口播中提及的画面内容**已验证**；画面帧细节（字幕样式/BGM/精确时长/转场）**仍待实片确认**，不冒充已验证。

## 逐条复核结论

### 1. 小天fotos《Tutor Skill 数学题转讲解视频》✅ 已验证

- 数据：2,964 赞 / 43 评论（与首轮一致）
- **工具链（口播逐字稿确认，从"推断"升级为"口播证据"）**：Manim（数学动画 Python 库）+ edgeTTS（脚本调用）+ Qwen3-TTS（可选音色克隆）+ Remotion（提及探索中）
- **六步流程（逐字稿确认）**：数学建模 → 网页可视化发散 → 分镜 spec → 先语音后画面 → 验证更新音频长度 → 脚手架
- **关键生产原则（逐字稿原话）**：
  - "先分镜，然后做语音，再根据语音长度来设计画面"（audio-first，避免音画不同步）
  - 脚手架固定代码结构 + 验证函数（自动测试）+ Fail Fast（渲染时验证函数出错立刻报错，AI 自动 review 修复）
  - 抽卡找风格后保存成 sample，控制后续生成稳定性
- **对我们的映射**：B组 Build 讲解动画管线必须采用 audio-first + 脚手架 + 验证函数三件套

### 2. Ai林爻《LLM 预训练费曼》✅ 已验证

- 数据：24,870 赞 / 532 评论（一致）
- **叙事结构（逐字稿确认）**：空白大脑开场 → 4步拆解（数据清洗/Token化BPE/训练预测下一个token/使用推理）→ DJ台旋钮类比 → 掷骰子收尾
- **对我们的映射**：一句话锚点（"预测下一个token"）+ 分步展开 + 生活类比（DJ台）= B组讲解动画标准结构

### 3. Ai林爻《RAG 费曼》✅ 身份与数据确认

- 数据：49,081 赞 / 787 评论（一致）
- 标题/标签确认（#ai产品经理 #RAG #文科生 #agent）
- 逐字稿未完整召回，但身份与数据可信

### 4. Simon林《CEO Agent 把自己替换了》✅ 已验证

- 数据：6,342 赞 / 376 评论（一致）
- **画面（口播逐字稿确认）**：真实 Web Dashboard 走查——排班表绿灯黄灯、本周销量、star数、总览/电商/内容/开源板块切换
- **关键发现**：口播明确说"我把店铺名称给隐藏起来了"——这就是**证据脱敏实践**，与本仓库 V2 设计的 redaction chain（裁剪变换收据）完全同构
- 背景：非程序员，5 天用 Claude Code Opus 5.5 从零搭建
- **对我们的映射**：A组 Explore 的 Dashboard 证据型录屏必须带脱敏步骤（隐藏店名/凭据/无关窗口），与仓库 redaction 契约对齐
