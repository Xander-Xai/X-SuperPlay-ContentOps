# Evidence ingest

Input: verified sources and claims registry.

Output: `01_research/claims-map.json`, a compact claims map containing `claim_id`, source IDs, evidence type
(`official`, `first_hand_test`, `inference`, `example`, `illustrative`), allowed
wording, and forbidden overclaims.

Do not write the final script here. The map must be materialized and passed
before the canonical script can be approved; this component exists to prevent
later copywriters from losing provenance while making the language lively.
