# 质量标准

[English](QUALITY-STANDARD.md) | [简体中文](QUALITY-STANDARD.zh-CN.md)

> 视频和内容质量门控。无凭证 = 任务未完成。

## 视频质量门控

| 门控 | 要求 |
|---|---|
| 分辨率 | ≥1080p |
| 帧率 | ≥30fps |
| 音频 | 48kHz / 立体声 |
| 时长 | ≤5min（短视频标准） |
| 字幕 | 正确显示，无遮挡 |

## 证据优先原则

所有声明必须可追溯到真实执行凭证。无凭证 = 声明无效。

## 人工审查门控

发布前必须有人工审查。自动化检查通过 ≠ 可发布。
