# ADR-022：Easel v0.3.0 工作台候选

状态：**接受分阶段实施——Owner 指令，2026-11-13**  
日期：2026-11-13  
Issue：[#173](https://github.com/Xander-Xai/X-SuperPlay-ContentOps/issues/173)  
关联：[ADR-016](ADR-016-easel-host-adoption.md)、[ADR-017](ADR-017-coding-agent-driver.md)、[ADR-021](ADR-021-stable-production-gates.md)

## 背景

ADR-016 将固定版 Easel 宿主作为生产底座，但接受的运行时是 v0.2.1，宿主面为只读。
Issue #173 评估把 v0.3.0 工作台作为候选入口。v0.3.0 源码树与 `.runtime/easel/` 不同；
上游 tag 曾变更，因此以完整 commit `bb3c8ff0463f36c202454d74171682ba6e470cb1` 为准。

候选版本增加 React 前端、账号画像文件和潜在 Agent 执行能力。仅过滤 HTTP 路由无法证明前端
来源、画像新鲜度、工具限制或操作系统隔离。现有 ContentOps 生产回执仍锚定于 v0.2.1 流水线。

## 决策

### D1——运行时角色保持分离

`.runtime/easel/` 继续作为 v0.2.1 生产候选，并由 `runtime/easel.lock.json` 固定。v0.3.0
仅是工作台候选，不改变生产路由、既有回执、生产锁或升级门禁。

### D2——工作台来源需要两项独立证明

overlay 校验器必须证明完整上游基线，并要求每个已存在的 overlay 文件都有 SHA-256 摘要。
前端构建需单独回执，绑定源码 commit、`package-lock.json`、Node/npm 版本、
`npm run build` 和 `web/frontend/dist` 的完整文件清单。已有 `dist` 目录或上游源码匹配都不构成
构建来源证明。前端证据缺失或产物变化时，受控宿主和浏览器资源读取必须阻断。

v0.3 候选宿主的上游页面只从已校验的 dist 清单提供 `/` 和 `/assets/`，返回前核对所请求的
文件字节，并拒绝清单外的旧版 `/static/` 与 `/onepage` 资源。内容安全策略限制外部资源，
但不构成操作系统网络隔离证明。该改动尚未运行或进行浏览器测试。
候选宿主对 HTML、JavaScript 模块、CSS 和 SVG 指定浏览器可用的 MIME 类型，避免依赖 Windows
注册表默认值；此改动同样尚未测试。

对本机两份 `video-script` 覆盖文件的审阅发现，它们包含账号策略和带时间范围的互动数据示例，
引用的来源笔记不在本仓库。现在两份源码副本位于
`extensions/easel-workbench/skills/builtin/video-script/`，overlay 校验器会逐一比对安装文件与仓库
源码摘要。原始 benchmark 转录及复核笔记仍缺失；历史示例和指标明确标记为未验证，不得作为当前事实。
源码副本使声明的 overlay 可重建，但不能证明历史主张为真，也不替代单独的再分发审查。

### D3——上游路由保持只读，另设单一离线任务接口

上游透传路由仍保持只读。对于框架任务，工作台 guard 接受精确的
`POST /api/contentops/draft-task`、`GET /api/contentops/draft-task/{task_id}` 和
`GET /api/contentops/draft-task/{task_id}/draft`。POST schema 仅含 `account`、`project`、
`brief`、`idempotency_key`；它调用确定性离线框架，不进入 Easel chat、模型、gateway、shell 或网络。
两个 GET 必须匹配账号和已有项目，并在返回前校验回执与草稿字节。接口限制请求体 32 KiB，提供幂等键、
项目级并发控制和精确路由。下文另述证据草稿接口；其他变更和未知路由均在上游之前拒绝。
提交及读取还要求已有项目的 `project.yaml` 中有唯一且与所选账号一致的
`account_slug`；未绑定账号的项目会被拒绝。
任务 ID 分配后的失败尝试会在项目内单独写入脱敏回执，记录失败代码与输入、DNA 摘要，
不覆盖幂等状态或成功回执；安全项目和任务尚未绑定前的错误只能返回调用方。该行为尚未测试。

独立的 `scripts/easel_host.py serve --offline-tasks-only` 模式会在回环地址提供 ContentOps
自有面板与 API，不导入或代理 Easel。默认端口为 7862，检查已安装的 `uvicorn` 和 PyYAML，其他路由一律
返回 404。其状态不依赖上游前端构建回执。它只在已有项目内写入离线框架或证据草稿；
生产与发布标记保持 false。本决策不代表已完成浏览器验收，也不启动宿主。
每条已允许路由的 `OPTIONS` 只报告该路由精确方法，不发送 CORS allow-origin 响应头；非回环 Origin 仍拒绝。

离线模式状态会给出默认面板地址，宿主命令启动时会打印所选回环地址。启动提示不证明端口已成功绑定；
此改动尚未运行或测试。

任务 POST 要求 HTTP Origin 的主机名和端口与 Host 一致；缺失、重复或不同源的请求头会被拒绝。
本地 CLI 不依赖此 HTTP 规则。该改动尚未运行或测试。

原始 `/api/chat`、画像／技能／产物读取、账号路由、凭据路由、发布路由、设置写入、安装路由和删除操作
仍然拒绝。未知路由、不安全 scope、路径穿越、跨账号读取以及未校验的浏览器产物均失败关闭。

v0.3.0 源码审计发现：`/api/personas` 会枚举全部画像目录并返回名称与身份描述；
`/api/persona/{name}` 和 `/files` 没有限定在 ContentOps 的两个账号 ID 内。技能列表和详情处理器会调用
`_read_env()` 计算 API 配置状态，因此会间接读取 `.env`。原始 `/api/chat` 会启动或代理 gateway 对话。
这些上游路由继续关闭；ContentOps 自有的离线任务路由不调用它们。

上游 `/api/skills` 和 `/api/status` 均调用会读取运行时 `.env` 的 `get_skills()`，因此
guard 拒绝这两个路由。ContentOps 自有画像、技能和项目接口不转发到它们。此修正尚未运行或测试。

`GET /api/contentops/status` 报告离线模式、网关未探测以及真实 Agent 执行未授权；它不以伪造的
已连接或未连接结果替代上游状态。此接口尚未运行或测试。

离线面板另提供 `GET /api/contentops/skills/video-script`，只读取固定的仓库自有
`SKILL.md`，每次请求核对 overlay 声明的来源和 SHA-256；内容变动时拒绝读取。该接口不开放
任意技能路径，也不调用上游技能处理器。内容中的历史案例仍须独立核实。

ContentOps 自有的 `GET /api/contentops/profiles/{account}` 在内存中将所选 DNA 投影成六个
画像文件并返回文本和摘要，不声称已核验安装快照或 Agent 上下文。对固定候选源码的静态阅读显示，
上游直连模式通过 `load_profile_text` 将画像文本加入系统上下文；Gateway 模式通过
`chat_turn_message` 和 `persona_prefix` 指明画像及读取位置，仅凭这条源码路径无法证明 Gateway
中的 Agent 实际读取了文件。此接口尚未运行或测试。
同一上游 `persona.py` 还会在 Gateway 对话消息末尾加入 `TURN_REMINDER`，其中涉及已登录账号和公开平台内容；它不能充当权限边界。ContentOps 继续关闭上游原始聊天，未来运行 Agent 前仍须独立证明工具、凭据和网络隔离。

独立画像校验器还会拒绝账号快照目录中未声明的条目，因为上游加载器会追加读取六个指定文件以外的
Markdown 文件。此校验器改动尚未运行或测试。

候选运行时解析和宿主启动要求生成画像校验模式：将安装快照和清单摘要与当前账号 DNA 的即时投影
比较；仅匹配历史清单不再足以将已变化的账号标记为最新。该新增检查尚未测试。

`GET /api/contentops/project-readiness` 只读报告所选项目的 Brief 审批、证据包充分性与
文档摘要、视频 Bundle 交接状态；它不授予生产权限，也不代替完整脚本校验。项目输入须位于允许的
非链接路径内。离线服务需要现有 PyYAML 依赖来核对项目账号。
响应还会摘要现有 agent driver 的回执状态和仅限人工的步骤，不返回可执行命令，也不执行步骤；
该摘要不代表流水线获得授权或具备生产条件。

`POST /api/contentops/evidence-draft` 接受账号、已有项目和幂等键，要求匹配且已批准的
Brief、已检查的证据包和视频 Bundle，然后在内存中调用现有 `contentops.script.draft.build`。
结果通过相同离线任务机制写入独立的项目 Markdown 草稿和回执，不覆盖生产脚本文件；回执绑定
Brief、证据包和 Bundle 摘要。它仍需人工复制评审，不是 Easel Agent 运行、生产许可或发布许可。
这一新增接口和行为尚未运行或测试。

离线面板可使用任务 ID 以及原账号、项目重新查看已完成任务，仍由既有回执和草稿校验控制读取；
面板不为其他项目或账号开放该任务。该查看界面尚未运行或测试。

证据任务还会保存绑定任务 ID 的 JSON，包含台词、声明映射、分镜和报告。读取
`GET /api/contentops/draft-task/{task_id}/artifacts` 时核对项目、账号、任务 ID 和记录的摘要；
这份 JSON 和 Markdown 都不会替代正式生产脚本。

### D4——没有系统隔离证明就不运行真实 Agent

可以开发和测试确定性离线执行器，但不得称为真实 Agent 执行。真实 Agent 任务需另行获批，并证明
低权限隔离：专用工作区、限定可写输出、不继承宿主凭据或浏览器状态、默认拒绝网络，以及经审计的具名
工具集。提示词不是安全边界。若无法在 Windows 证明这些属性，任务保持 `BLOCKED`。

Windows 候选包含沙箱启动原型和 Node 层输出捕获。启动入口无条件拒绝执行，本地回执或环境变量
均不能启用；原型和捕获代码尚未运行，捕获也不覆盖原生或子进程写入。这些组件不证明系统隔离，
也不构成真实任务授权。

静态阅读已安装的 OpenClaw 2026.10.5 工具策略文档发现：即使 `minimal` 画像也包含 Gateway
更新能力；`coding` 还包括运行时、网页和会话工具组。二者都不能直接作为本任务的默认白名单。
未来的隔离执行器除证明操作系统隔离外，还须显式拒绝不需要的工具和插件；此处尚未实际运行该策略。

显式选择的 v0.3 候选合成器继续使用现有 `assemble_easel.py` 适配器，中间文件和最终视频写入
项目内独立的 `work/easel-v030-candidate/<run-id>/`，并生成单独的
`build-easel-v030-<run-id>.json` 回执。候选子进程使用精简环境与独立临时目录；这不构成已证明的
操作系统沙箱，也不代表生产迁移，候选产物仍需 QC 与人工审核，生产 pin 不变。该改动尚未运行或测试。

候选合成前，适配器依据项目既有素材清单与权益规则核对实际使用的画面、背景音乐和音效；配音须匹配
既有配音回执。它记录输入摘要，输入缺失或变化时阻断，不静默跳过已声明的音轨。上述检查尚未运行验证。
仅要求解析分镜实际引用的素材；清单中未使用的缺失或无效条目不会阻断合成。实际使用的素材仍须有
唯一的清单条目、匹配的摘要和适用的权益依据。

候选文章适配器将预览和回执写入独立的项目路径，并精简子进程环境。候选卡片渲染仍被阻断：
上游渲染器会启动可能访问远程资源的浏览器，隔离浏览器和网络的边界尚未建立。上述改动尚未运行或测试。

### D5——证据和交付仍由 ContentOps 管理

生成草稿必须绑定所选账号 DNA、任务输入、运行时和构建身份，并接入现有项目回执链。生成文本不是
证据。通过既有 QC、人工审核和交付门禁之前，`production_ready` 与 `publish_authorized` 均保持 false。
本决策不授权连接账号、Provider 花费或外部发布。

## 后果

- 工作台可以并行准备，不移动 v0.2.1 固定版本。
- 依赖、上游字节、overlay 和前端构建均验证通过前，宿主保持阻断。
- 隔离离线面板可在未来浏览器审查时运行，而无需加载当前受阻的上游工作台；运行仍需操作员另行明确执行。
- 与账号 DNA 不一致的画像快照会被拒绝；刷新现有本地画像属于独立文件修改，需审查。
- 真实任务、浏览器验收和生产迁移是各自需要证据的不同里程碑。本 ADR 不授权安装依赖、启动宿主、
  模型／网络调用、提交、推送、PR 或清理旧运行时。

## 重新审议

若工作台需要修改上游、经审计路由暴露所选项目／账号以外的数据、无法从固定源码和锁文件重建前端，
或计划将生产运行时从 v0.2.1 切换时，重新审议本决策。
